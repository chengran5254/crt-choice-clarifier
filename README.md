# CRT-选择澄清器

一个帮助你把「不知道怎么选」「要不要继续」「几个方案各有利弊」转成可比较选择的 AI Skill。

它先澄清你的目标、偏好和底线，再比较从现在开始的投入、收益与真实替代机会。信息足够时给出建议；信息不足时只补关键缺口，或提出可执行的验证计划。

## 适用场景

- 比较工作、学习、生活或项目中的几个方案。
- 判断一件已经投入时间或金钱的事是否值得继续。
- 看清无法同时满足的偏好，以及每个选择要接受的代价。
- 找出什么事实或条件会改变当前建议。

## 安装

本仓库根目录就是一个完整的 Skill。下载仓库 ZIP 并解压，将整个文件夹改名为 `crt-choice-clarifier`。

### Codex

把文件夹放到 `~/.agents/skills/crt-choice-clarifier/`。确认 `SKILL.md` 直接位于该文件夹下，再重新打开会话，确认技能列表中出现「CRT-选择澄清器」。

### Claude Code

个人使用时，把文件夹放到 `~/.claude/skills/crt-choice-clarifier/`；仅用于某个项目时，放到该项目的 `.claude/skills/crt-choice-clarifier/`。

其他支持 `SKILL.md` 的工具，请按各工具的技能安装方式添加整个文件夹。不同工具对菜单配置和自动调用的支持可能不同。

## 使用示例

在支持 Skill 的工具中显式调用 `crt-choice-clarifier`，并说明当前选择。例如，在 Codex 中输入：

```text
使用 $crt-choice-clarifier，帮我比较这两份工作：
收入相同，一份稳定但工作内容无聊，另一份我很感兴趣但经常加班。
我希望每周至少有三个晚上能陪家人。
```

也可以问：

```text
使用 $crt-choice-clarifier。我已经花了 8000 元学剪辑，不能退，
但现在不确定还想不想做剪辑。继续一个月需要 1000 元和 30 小时。
帮我判断要不要继续；缺少关键信息时，每轮只问一个问题。
```

通常会得到：当前倾向、决定性理由、需要接受的代价、建议改变的条件，以及下一步行动。简单选择会直接回答，不强制生成表格或完整问卷。
